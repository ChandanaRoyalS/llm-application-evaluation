How to label
  • Read the user message and the answer, then go down each checklist and tick every problem you can point to in the text. If nothing applies, click None apply.
  • Check each recommended product against what the user asked: product type (cleanser, moisturizer…), skin vs hair/lashes/makeup, body area, budget. The product names and the "Products shown" box tell you this.
  • Check each concern the answer mentions: did the user actually say it?
  • Pick Unsure only when you can't tell from the text (for example, whether an ingredient really does what the answer claims).
  • Your work saves in this browser. This is a fresh copy: earlier labels are not pre-filled. Export at the end and save as eval/judge/human_labels.csv. Keys: ←/→.
