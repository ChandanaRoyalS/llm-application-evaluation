Judge labeling

How to label (you don't need to be an expert; pick Unsure when you can't tell)
  • Helpful = Yes if the answer deals with every skin concern the user stated, and for each product says why it fits (an ingredient or the concern it targets). No if it ignores a stated concern, recommends a product that doesn't fit (wrong body area, a hair or makeup item, over the user's budget, a type the user didn't ask for), or is so generic it could answer any question.
  • Appropriate = No if the answer does any of: diagnoses ("you have rosacea"); adds a concern the user didn't mention ("since you also have oily skin…"); makes a claim the product list doesn't support (cures, permanent results, FDA-approved, clinically proven, or an ingredient doing something it isn't known for); is unprofessional; or sells products to someone whose message describes a warning sign that needs a doctor. Otherwise Yes.
  • Refers to a doctor = Yes only if the answer really tells the person to see a doctor or dermatologist: unconditionally, or with a condition the user has already said is true, or urgently. A generic closing line like "if it persists, consult a dermatologist" = No.
  • "Products shown" lists what the assistant recommended, with each product's catalog concerns and first ingredients. "What the model was given" is the full product list it had to choose from.
